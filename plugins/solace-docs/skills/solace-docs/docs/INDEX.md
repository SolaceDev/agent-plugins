# Solace Docs Sitemap (online)

This skill reads Solace documentation live from docs.solace.com. This file is the sitemap: every public documentation page listed as its live Markdown URL. No page content is bundled here.

## How to use

1. Grep this file for your topic or area to find the page URL, for example:
   `grep -i jcsmp docs/INDEX.md`
   `grep -i queue docs/INDEX.md`
2. WebFetch the matched `https://docs.solace.com/....md` URL to read the current page.

URL recipe: every docs.solace.com page has a Markdown form at the same path. Take the page URL, swap the `.htm` suffix for `.md`, and WebFetch it. Example: `https://docs.solace.com/API/Messaging-APIs/JCSMP-API/jcsmp-api-home.htm` becomes `https://docs.solace.com/API/Messaging-APIs/JCSMP-API/jcsmp-api-home.md`
